## Featured projects

### [SmartCart](https://github.com/jad-obeidd/smartcart) — AI shopping assistant
Turns *"taco night for 4"* into a priced shopping list, understands searches like *"healthy snacks under $5"*, recommends products and streams live price changes over Server-Sent Events.  
**Tech:** React, Bootstrap, Node.js, Express, MongoDB, OpenAI API, JWT

### [Sentiment Analyzer](https://github.com/jad-obeidd/sentiment-analyzer) — NLP web app
Classifies text as positive, neutral or negative with a DistilBERT model, with history, filters and statistics stored in SQLite.  
**Tech:** Svelte, Flask, SQLite, Hugging Face Transformers (DistilBERT)

### [Guidely](https://github.com/hadi-chebbo/Guidely) — Team project, Frontend Team Lead
University-major guidance platform for Lebanese students, built by a 7-person team in 37 days. I led the frontend: design system, component architecture and admin panel, plus the majors page, search, pagination and quiz flow.  
**Tech:** Next.js 14, Tailwind CSS, React Query, Laravel 11 API, MySQL  
**My merged work:** [Majors page](https://github.com/hadi-chebbo/Guidely/pull/26) · [Search](https://github.com/hadi-chebbo/Guidely/pull/43) · [Pagination](https://github.com/hadi-chebbo/Guidely/pull/47) · [Quiz flow](https://github.com/hadi-chebbo/Guidely/pull/83)
